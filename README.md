# Jump Space Graphics Menu

Ouvrir le menu → touche F6
Fermer le menu → touche Échap
Réglages disponibles :
Qualité globale
Textures
Ombres
Distance des ombres
Antialiasing
Filtrage anisotrope
VSync
Limite de FPS
Échelle dynamique

Prérequis :
MelonLoader est obligatoire pour faire fonctionner ce mod.
